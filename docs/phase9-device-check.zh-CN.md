# Plus9 修复与验收

## 堆叠自动回缩

用户反馈：保留高德通知时自动回缩，划掉后不再发生。源码确认 LockIslands.commit 在每次通知管线提交后安排 foldIfPiled，350ms 后若系统状态为 STACK 则强制 NUMBER。通知内容更新并不代表用户要求收起。

修改：取消通知更新触发的折叠；胶囊行重复显示不再重复安排初始化折叠；初始化检查遇到正在运动的状态直接取消，不跨越手势重试；禁用折叠时清除待执行检查。手动收起路径保留，导航图标反色未改动。

此链路与反馈吻合，但尚未通过真机日志确认是唯一原因。NumState 保留已有 piled 原因日志，并记录因运动取消的检查。

## 歌词位置与媒体入口

胶囊歌词固定首次有效布局区域，时钟后续目标位置变化不再重排；真实尺寸/样式变化或隐藏后重新打开会重新测量。整体入场运动与容器透明度解耦，保留从下方入场及可打断反馈。媒体卡入口优先恢复已请求的歌词背景，尊重原封面开关和正在显示的导航背景。

## 验证

本地纯逻辑测试 262 项通过，包括新增的位置锁定、快速反向切换、透明度变化不逆转入场、媒体入口背景策略测试。git diff --check 通过。尚未完成 Android 云端构建或真机验证。

真机待测：
- 保留高德通知并持续导航，展开堆叠后等待多次通知更新，确认不自行回缩。
- 导航、歌词互切及上滑媒体卡后，展开状态保持；手动下滑仍能收起。
- 普通通知新增/移除、锁屏重入及模块开关后，堆叠可正常展开与收起。
- 胶囊打开歌词无上下抽动；快速开关、上滑、切歌后位置正确。
- 媒体通知内打开歌词保留原配置背景，导航背景不被抢占。

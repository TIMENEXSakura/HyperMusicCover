# 集成验证说明（不作为单个上游 PR 提交）

## 问题与行为

TTML 同一主唱行携带多段和声时，当前转换只保留第一段；部分时间区间重叠、纯和声行及异常逐字边界也可能导致内容丢失或不完整。本次在现有上游修复和用户分支基础上保留全部和声，各自建立时间轴与渲染数据，并增加输入边界检查。

当前上游已支持 Lyricon 的 secondaryWords 和全文／词表不一致时的重建，此次整合不将其列为首次修复。用户曾遇到的 v0.9.3 SystemUI 崩溃缺少可对应的原始堆栈，本文不把推测写成已确认根因。

## 修改内容

- 保留主唱／多段和声、逐字时间及合法重叠；无效逐字数据降级为逐行文字，继承上游解析和绘制异常隔离。
- 使用 MIUIX 设置主唱／和声独立字号、官方／封面莫奈／自定义／系统动态颜色，配置保存及备份恢复。
- 默认按词幕、元数据、同目录文件、各网络源顺序获取；原有 MIUIX 列表手柄可拖动排序，解析失败依次回退，低优先级迟到结果不能覆盖高优先级。
- 联网开关默认开启，关闭时从请求入口阻断网络歌词获取；同目录格式默认 TTML 优先、LRC 次之，格式排序与来源排序独立。
- 胶囊主体先匹配专属行为，再考虑通知展开：音乐切换歌词，导航切换已有导航内容，闹钟／计时器复用已有功能入口。专属行为暂不可用时不继续展开通知列表。
- 保留上滑与独立按钮操作；添加最低 0.65 的播放按钮按压缩放，以及可连续更新的短暂状态提示，恢复当前真实播放状态。
- 单色控件按胶囊材质取色，应用图片选择对应深浅资源，不统一染白多色图标。

- 第二阶段加入独立歌词页面、导航文字状态替换、可打断的“词／对勾／叉号”反馈，避免点按再次走入媒体卡展开。
- 两种来源优先级独立：全局可拖动列表；同目录 TTML／LRC 锚点菜单，旧配置迁移后只读新键。
- 词幕状态直接来自框架连接与活动提供方反馈；断开不再显示运行中。高德单色方向图标增加最终图片处理及有界诊断，仍须真机确认。
